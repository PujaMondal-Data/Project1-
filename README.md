# Sales Performance Dashboard-Excel
An interactive sales performance dashboard created using Microsoft Excel to analyze sales, profit, customer segment, product categories, regions, shipment modes, and monthly trends.
KEY ANALYSIS --> Top 5 profitable state , Top 10 most profitable city, Bottom 3 least profitable sub-Category, Shipment mode analysis, Regional sales and profit performance, Monthly sales & profit trend ,Interactive slicer and timeline.
TOOLS USED--> Microsoft Excel | Pivot Tables | Pivot Charts | Slicer | Timeline | Data Analysis

INSIGHTS --> South Region generated substantial sales but incurred a loss , indicating a need to investigate regional profitability.
Profitability improve significantly after march, despite fluctuations in monthly sales.
